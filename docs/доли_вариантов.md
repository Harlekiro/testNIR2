# Доли вариантов Ж+К+ОД и К+ОД по фактическим кварталам

Метод — решение автора 23.11.2026. Расчёт: `python docs/доли_по_типам_кварталов.py` (таблица —
`results/доли_по_типам_кварталов.csv`). В `mixuse/params.py` результаты входят в `EMPIRICAL_SCENARIOS` и используются по умолчанию. Прежние Ж+К+ОД = 75 / 5 / 20 / 0 и К+ОД = 0 / 15 / 85 / 0 сохранены в экспериментальном наборе.

## Метод расчёта

1. **Поэтажная площадь квартала по группам** — из таблицы зданий пакета (правила раздела 4 ТЗ):
   - Ж — поэтажная площадь жилых домов без встроенных помещений;
   - К, ОД — поэтажная площадь нежилых зданий группы (площадь застройки от S_min = 200 м²) плюс встроенные
     помещения группы в жилых домах;
   - П — нежилые здания группы П;
   - здания группы X (функция не определена) не учитываются.
2. **Функция присутствует в квартале**, если её доля в поэтажной площади Ж + К + ОД + П **не меньше 5 %**.
   Тип квартала — набор присутствующих функций: «Ж+К+ОД» — присутствуют ровно Ж, К и ОД; «К+ОД» — ровно К и ОД.
3. **Доли квартала** — доли функций его типа, приведённые к 100 % (функции с долей меньше 5 % отбрасываются).
4. **Доли варианта** — медиана долей по всем кварталам этого типа **трёх городов вместе** (Высоцк, Гатчина,
   Санкт-Петербург), по каждой функции. Медианы приводятся к 100 % и **округляются до 5 %**; если после
   округления сумма не 100, 5 % добавляются (или снимаются) у функции с наибольшим остатком округления.

Медианы по отдельным функциям в сумме не дают 100 % (Ж+К+ОД: 45,2 + 12,2 + 34,5 = 91,9), поэтому они приводятся
к 100 % перед округлением: 49,2 / 13,3 / 37,5 → 50 / 15 / 35.

Замечания:
- В Высоцке кварталов обоих типов нет; 92 % кварталов — петербургские, поэтому итог близок к медианам Петербурга.
- Прежние 75 / 5 / 20 этим методом не получаются: доля жилья ниже (50 %), доли К и ОД выше.
- Историческое обоснование Ж+К+ОД в 4.6.1 ТЗ относится к прежним долям. Для эмпирической версии основание — медиана кварталов этого типа в объединённой выборке.
