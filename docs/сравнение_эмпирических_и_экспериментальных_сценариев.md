# Сопоставление эмпирических и экспериментальных сценариев

- `EMPIRICAL_SCENARIOS`: только подтверждённые доли Ж+К+ОД (50/15/35) и К+ОД (35/65). Доли остальных типов **ещё не рассчитаны**.
- `EXPERIMENTAL_SCENARIOS`: исходные пять авторских сочетаний; два варианта переименованы в К+ОД+П и Ж+К+П, доли не менялись.
- `SCENARIOS`: совместимый набор по умолчанию — **смешанный**, не выдавать его за полностью эмпирический.
- `paired_scenarios()`: семь вариантов с полными названиями, например `Ж+К+ОД [эмп.]` и `Ж+К+ОД [эксп.]`. Передайте этот набор в `compare_v5(city, T, P, paired_scenarios())` или во вспомогательные проверки. Полные названия сохраняются в таблицах и полях доступа GeoJSON.
- `SCENARIO_ORIGINS`: происхождение каждого варианта для отчётов.

## Правило сравнения

При одинаковой территории, КИТ и параметрах сравнить каждый вариант с «Как есть»; для двух типов, где есть обе версии, сравнить экспериментальный вариант с эмпирическим. Не считать разницу между типами функцией только долей: состав функций тоже различается. Сравнение не является ранжированием качества.

## Совместимость

Пользовательские YAML-файлы с произвольными подписями сценариев не переименовываются автоматически. Если в них встречаются названия `ОД+П` или `Ж+П` при ненулевой К, следует обновить подписи вручную. Чтобы использовать `paired_scenarios()` в командной строке, добавьте `--paired` к команде `compare`. В конструкторе выберите «2 эмпирических + 5 экспериментальных».

## Исторические эталоны Высоцка

Шесть исходных CSV сохранены в [`tests/etalon/v5_legacy/vysotsk/`](../tests/etalon/v5_legacy/vysotsk). Их заголовки и значения воспроизводятся при следующих долях поэтажной площади.

| Историческое название | Ж, % | К, % | ОД, % | П, % |
|---|---:|---:|---:|---:|
| Ж+К | 85 | 15 | 0 | 0 |
| Ж+К+ОД | 75 | 5 | 20 | 0 |
| К+ОД | 0 | 15 | 85 | 0 |
| ОД+П | 0 | 10 | 40 | 50 |
| Ж+П | 50 | 10 | 0 | 40 |

Для воспроизведения задайте эти пять вариантов в `scenarios` копии `configs/vysotsk.yaml`, сохранённой в папке `configs/`. Запустите `python -m mixuse compare` с этим файлом и отдельной папкой вывода `--out`. Для расчёта школ и садов установите `MIXUSE_PROVISION=fallback`. Территория, параметры и исходные слои берутся из настроек Высоцка.

Текущие CSV в [`tests/etalon/v5/vysotsk/`](../tests/etalon/v5/vysotsk) рассчитаны с пятью сценариями `SCENARIOS` по умолчанию. Проверки ноутбука Высоцка продолжают сверять шесть таблиц с историческими CSV, поскольку ноутбук задаёт прежние сценарии явно.
